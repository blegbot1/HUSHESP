# HUSHESP

ESP and utility script for HUSH: They can hear. (BETA) (Roblox).

## Loader

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/HUSHESP/main/HUSHESP.lua",true))()
```

Or via loader:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/HUSHESP/main/loader.lua",true))()
```
